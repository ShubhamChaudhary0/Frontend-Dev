# Live Search & Dashboards (Q1-Q6)

## What this script does
- Creates frontend demo pages q1.html .. q6.html
- Creates a sample db.json for json-server

## Prerequisites
- Node.js and npm installed

## Run
1. Start json-server:
   npx json-server --watch db.json --port 3000
2. Open index.html in your browser (use a static server or open file directly). For full CORS consistency, open via local server (e.g. `npx http-server .`)
